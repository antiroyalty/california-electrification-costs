# Research Log — 2026-08-13

## Solver-output numerical tolerance

The NBT preflight found tiny negative exports in three generated county files:
Butte (`-1.1322133e-09` kWh), Colusa (`-3.0257966e-12` kWh), and San Mateo
(`-1.6396718e-09` kWh). These are below the optimizer's existing `1e-7` kWh
meter-direction feasibility threshold and are numerical solver residue rather
than physical negative energy.

Step 9b now makes the solver boundary explicit: any nonnegative decision value
whose absolute magnitude is at most `1e-7` is normalized to exact zero. A value
below `-1e-7` raises an error instead of being repaired. Operating costs are
recomputed from the normalized flow series so financial diagnostics and saved
physical flows remain consistent.

Billing and preflight retain their strict input contract: generated artifacts
must contain finite, nonnegative energy values. They do not apply a second
tolerance or silently clamp upstream results.

Deferred operational cleanup: invoking `step9b_cooptimize_pv_battery.py`
directly fails because it uses package-relative imports. The working command is
`python -m pipeline.steps.step9b_cooptimize_pv_battery`; its CLI documentation
should be made consistent in a separate change.

## 2026-08-14 follow-up: align with HiGHS MIP feasibility

The first statewide run after this change exposed a larger, but still
solver-scale, residue in San Diego: simultaneous import of
`0.4929981117540997` kWh and export of `5.400264010162599e-7` kWh at hour 5129.
The interval already had a binary meter-direction constraint. HiGHS accepted
the result because its default MIP feasibility tolerance is `1e-6`, while the
new post-solve guard was stricter at `1e-7`.

The shared solver-output and meter-direction tolerance is therefore `1e-6`
kWh, aligned with the solver's documented feasibility boundary. Values within
that boundary are written as exact zero; values beyond it still fail loudly.
Even if the full tolerance occurred in all 8,760 intervals, it would represent
only `0.00876` kWh annually, below the precision of reported household-energy
and billing results.
