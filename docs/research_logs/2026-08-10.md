# Research Log — 2026-08-10

## Future development: fail-loud research validation command

Advisor-facing requirement (Duncan Callaway): add a dedicated research
validation command that verifies a completed end-to-end modeling run. Missing
research artifacts must fail this command rather than appear as ordinary
pytest skips.

This should remain distinct from the fast, self-contained unit-test suite:

- `pytest` continues to run unit, behavior, source-data, and small-fixture
  tests without requiring gigabytes of generated outputs.
- A separate command, provisionally `make research-validate` or
  `python -m scripts.validate_research_run`, requires a specified completed run
  and treats every missing prerequisite as an error.

The research validation command should:

1. Require and identify the run configuration: Git commit, tariff snapshot
   date, NBT interconnection vintage, billing year, incentive regime, counties,
   housing type, and relevant solver settings.
2. Verify that every required pipeline-stage artifact exists for every county,
   including load profiles, weather, dispatch, billing, capital-cost, and
   reconciliation outputs.
3. Run the existing assumption-based ballpark tests against those artifacts,
   including energy conservation, import/export direction, annual consumption,
   export-credit magnitude, bill magnitude, and cost reconciliation. This is the most key part of the research validation, and the part that Duncan will be most interested in its correctness. The ballpark values should be correct based on prior research and documented industry constraints.
4. Fail—not skip—when an artifact, county, tariff identity, source hash, or
   required metadata field is missing.
5. Emit a compact machine-readable and human-readable validation report with
   passed checks, failures, warnings, artifact paths, and provenance.

Suggested pytest organization if markers are used:

```text
pytest -m "not research_validation"       # fast development suite
pytest -m research_validation             # completed-run artifact checks
