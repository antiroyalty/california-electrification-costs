# Research Log — 2026-08-12

## NBT end-to-end input preflight

The new fail-loud NBT preflight was run against all 47 generated county
profiles in `induction_stove_coopt` using billing year/vintage 2026, the
2026-08-09 import-tariff snapshot, and the 2026-08 true-up month.

- 44 county artifacts passed.
- Every passing artifact was an annual net importer, so no NSC/EEC adjustment
  lookup was required. The missing PG&E adjustment-rate source therefore does
  not block Step 12 for these particular artifacts; it remains a blocker for
  any future PG&E annual net-exporter profile.
- Three artifacts failed because `nem3.exports.kwh` contains negative values:
  Butte (minimum `-1.1322133e-09`), Colusa (`-3.0257966e-12`), and San Mateo
  (`-1.6396718e-09`). These magnitudes look like solver numerical residue, but
  the preflight does not silently clamp them. The upstream optimization-output
  boundary needs an explicit, tested numerical-tolerance policy before these
  profiles are regenerated and the statewide billing run proceeds.

Command used:

```bash
python3 scripts/validate_nbt_run_inputs.py induction_stove_coopt --all-counties
```
